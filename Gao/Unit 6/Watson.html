  1. Convert the Attrition column from the character type to the factor type. This is necessary because the dependent variable in a classification model must be of the factor type.
Watson$Attrition <- as.factor(Watson$Attrition)
  1. Drop all columns of the character type that only have a single unique value. This is necessary because having an independent variable that only has a single unique values causes an error if you attempt to tune a classification model.

I chose these three variables by looking at the tibble in the environment pane

Watson <- select(Watson,-c(EmployeeCount, Over18, StandardHours))
  1. Split the data into testing and training sets

I used a 75-25 split

Watson_split <- initial_split(Watson, prop = 0.75)

train <- training(Watson_split)

test <- testing(Watson_split)
  1. Create a decision tree model with a depth of 30 and a minimum of 5 data points per node
dtree_mod <- decision_tree(mode = "classification", min_n = 5, tree_depth = 30)
  1. Fit the model to predict the Attrition variable given all of the remaining variables in the data set.
dtree_mod_fit <- fit(object = dtree_mod, formula = Attrition ~ ., data = train)
  1. Plot the model.
dtree_mod_fit %>% extract_fit_engine() %>% rpart.plot()
